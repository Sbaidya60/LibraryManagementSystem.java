# 📚 Library Management System (Java Console Project)

This is a simple **Library Management System** developed using Java for beginners. It uses console input/output to manage books in a library.

## 🚀 Features
- Add new books
- Display all books
- Search for a book by title
- Delete a book by ID
- Exit the system

## 🛠 Technologies Used
- Java (JDK 17+ recommended)
- Console-based UI (Scanner class)

## 📂 How to Run
1. Download or clone the repository.
2. Open the project in your favorite IDE (like IntelliJ IDEA, Eclipse, VSCode).
3. Compile and run `LibraryManagementSystem.java`.

```bash
javac LibraryManagementSystem.java
java LibraryManagementSystem
